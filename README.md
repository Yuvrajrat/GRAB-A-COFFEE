# GRAB-A-COFFEE
A visually appealing and responsive website for a coffee shop. Features include menu display, location information, and a stylish design using HTML, CSS, and JavaScript.
<br>
Features
<br>
Modern Design: Aesthetic and user-friendly design.
<br>
Interactive Menu: Displays coffee options and prices.
<br>
Location Details: Information on store location and contact.
<br>
Responsive Layout: Optimized for desktops, tablets, and mobile devices.
